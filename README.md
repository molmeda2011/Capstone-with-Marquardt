# Capstone-with-Marquardt - Data Analysis/Soft Engineering Project
## PMDCI developed by Sean Schukraft | ART developed by Ahmad Black and Matthew Olmeda
ART (Andon Reporting Tool) and PMDCI were completed at the request of Marquardt Switches Inc. The purpose of ART was to take user and factory data and convert it to easy-to-understand live graphs, provide alerts, and information.\

For PMDCI, navigate to appropriate location and use `npm run devStart` to run the server and `npm start` to run the front end.\

Python, HTML, Java-script, CSS, and Flask were used to complete this project
